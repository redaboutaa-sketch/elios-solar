# ELIOS SOLAR — boutique pergolas & aménagement extérieur

> Nom d'affichage **provisoire** déduit du nom du dépôt ; modifiable centralement
> (`config/brand.ts`). Il ne constitue pas une identité juridique validée.

Boutique e-commerce française de pergolas bioclimatiques, stores bannes et
accessoires d'aménagement extérieur, avec configurateur, calcul de prix serveur,
devis, commande en mode test et administration.

Documentation de pilotage : voir `docs/` (PRD, audit de référence, parité
catalogue, matrice de compatibilité, architecture, tâches, état, décisions,
blocages de lancement).

Dépôt public : aucun secret, aucune donnée client réelle. Les jeux de données
fournis sont fictifs et marqués `DEMONSTRATION`.
